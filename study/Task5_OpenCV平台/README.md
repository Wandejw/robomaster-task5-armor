# Task5 OpenCV 精选题离线学习平台

这是一个基于 `ImageProcessing100Wen` 的个人 C++ 视觉算法知识库。平台只保留学习路线中的 23 道重点题，并保留原题号。所有页面和数据均在本地，不依赖网络、Node.js 或 npm。数学公式使用平台内置的 KaTeX 离线资源排版，分段函数、矩阵、求和与嵌套分式均不需要联网加载。

保留题号：`1、2、3、4、5、7、9、10、11、15、16、17、20、21、22、23、25、26、27、28、29、30、43`。

- 深入理解并自己实现：1、2、3、5、7、9、10、11
- 深入理解并看懂源码：15、17、43
- 理解原理并看懂源码：4、16、20、21、22、23、25、26、27、28、29、30

## 运行方式

直接双击 `index.html` 即可打开。

## 重新生成题库数据

在终端进入 `tools` 目录后运行：

```bash
python3 generate.py
```

生成器会扫描平台内的 `ImageProcessing100Wen` 副本，然后更新：

- `data/questions.json`：标准 JSON 数据；
- `data/questions.js`：与 JSON 内容相同，用于解决浏览器直接打开 `file://` 页面时无法 `fetch` 本地 JSON 的限制；
- `assets/images`：README 中引用的本地图片；
- `assets/codes`：已找到的 C++ 答案副本。

当前仅处理 C++ 答案，不读取 Python 文件。

## 学习数据

完成状态、收藏、笔记和最近学习使用浏览器 `localStorage` 保存，不会上传到网络。请尽量使用同一个浏览器和同一个 `index.html` 路径打开平台，否则不同浏览器可能会使用不同的本地存储空间。

为避免 `file://` 把首页和题目页分配到不同的本地存储空间，题目详情现在通过 `index.html#question=题号` 在首页内切换。旧的 `question.html?id=题号` 链接会自动转到新入口。数学任务页通过同标签页状态桥接把进度同步回首页。

## 数据边界

题目标题和 README 来自原仓库。如果某题没有 `answers_cpp/answer_x.cpp`，平台会将 C++ 内容保留为空，不会自动伪造答案。
